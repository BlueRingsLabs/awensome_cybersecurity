# Catalog schema

The library is published as two byte-stable, machine-readable catalogs:

- [`index.json`](../index.json) — canonical JSON;
- [`index.yaml`](../index.yaml) — the same data in YAML.

Both are generated by `cyberkb build` and validated in CI against
[`schema/catalog.schema.json`](../schema/catalog.schema.json) (JSON Schema
2020-12). The catalog also carries its own `schema_version` and a self-
describing `taxonomy` block, so a consumer can interpret it without reading this
repository.

## Top level

| Field | Type | Meaning |
| --- | --- | --- |
| `schema_version` | string | Catalog schema version (semver), currently `2.0.0`. |
| `generated_at` | string (date-time) | UTC build time; the only non-deterministic field. |
| `generator` | string | Always `cyberkb`. |
| `repository` | object | Name, organization, URL, licence, description. |
| `taxonomy` | object | The full taxonomy: categories (with CyBOK/NICE codes), formats, languages, tags, and the CyBOK/NICE code tables. |
| `counts` | object | `total` and breakdowns `by_category`, `by_format`, `by_language`, `by_redistribution`. |
| `entries` | array | One object per resource, ordered by category, then title, then id. |

## Entry

| Field | Type | Notes |
| --- | --- | --- |
| `id` | string | Stable `ckb-<12 hex>`, derived from content; survives renames/moves. |
| `title` | string | Human title. |
| `category` | string | One taxonomy category id (the folder). |
| `format` | string | One taxonomy format id. |
| `language` | string | `en` \| `es` \| `pt` \| `und`. |
| `path` | string | Repo-relative path under `library/`. |
| `tags` | string[] | Controlled-vocabulary tags, unique. |
| `summary` | string | One neutral sentence (may be empty for heuristic-only entries). |
| `authors` | string[] | Always non-empty; `["unknown"]` when none is declared. |
| `source_url` | string (uri) | Present only when known. |
| `reference_only` | bool | Present and `true` when the entry is a pointer to a work not hosted here (see below). |
| `license` | string | SPDX id, `LicenseRef-*`, or `NOASSERTION`. |
| `redistribution` | string | `permitted` \| `noncommercial` \| `restricted` \| `unknown`. |
| `added` | string (date) | When the resource entered the library. |
| `word_count` | integer | Body word count. |
| `size_bytes` | integer | On-disk size. |
| `sha256` | string | SHA-256 of the sanitised body (change detection). |
| `classification` | object | `method` (`llm`/`heuristic`/`manual`), `confidence` (0–1), optional `model`. |

## Reference-only entries

An entry with `reference_only: true` is a maintainer-written pointer to a work
this repository does **not** host — typically an all-rights-reserved third-party
work. It carries the title, an author credit, a `source_url` and a short
summary, and nothing of the original text (the policy check caps it at 400
words). `license` records the upstream work's licence and `redistribution` is
`restricted`. Consumers should link out via `source_url` rather than expect a
local body.

## Stability contract

- `id` values are stable across renames and re-categorisation; treat them as the
  primary key.
- `entries` ordering is deterministic.
- New *optional* fields may be added in a minor `schema_version`; removals or
  semantic changes bump the major version.

## Examples

```bash
# Count resources per redistribution class.
jq '.counts.by_redistribution' index.json

# All openly redistributable OSINT resources.
jq -r '.entries[]
       | select(.category=="threat-intelligence-and-osint" and .redistribution=="permitted")
       | .path' index.json

# Resources still needing a licence confirmation.
jq -r '.entries[] | select(.license=="NOASSERTION") | .path' index.json
```

```python
import json, urllib.request

BASE = "https://raw.githubusercontent.com/BlueRingsLabs/awesome_cybersecurity/main"
catalog = json.load(urllib.request.urlopen(f"{BASE}/index.json"))  # noqa: S310
books = [e for e in catalog["entries"] if e["format"] == "book"]
print(len(books), "books")
```
