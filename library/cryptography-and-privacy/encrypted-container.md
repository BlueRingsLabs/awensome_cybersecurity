# Encrypted container

I recently needed an encrypted container to store files on a Linux virtual machine (Debian 13 with XFCE). I didn’t want to encrypt the entire disk so that it wouldn’t take up too much space, so I decided to create a simple, encrypted container that I could mount and store important files on. Additionally, I wanted to mount it using a ready-made command, and then I added a small GUI written in Python that starts with the system and shows the container mounting status. Perhaps you are looking for a similar solution and will find what I came up with useful.

Of course, I could have used ready-made solutions such as [VeraCrypt](https://veracrypt.io/en/Home.html), [zuluCrypt](https://mhogomchungu.github.io/zuluCrypt/) or [Cryptomator](https://cryptomator.org/) but I wanted the solution to be as simple as possible, one that did not rely on external programs, but on proven solutions integrated into the system. I’m not saying that third-party solutions are bad. It’s just that sometimes it’s worth creating something of your own based on the solutions available in the system.

- [Cryptsetup + LUKS2](https://gitlab.com/cryptsetup/cryptsetup) uses the [dm-crypt](https://www.saout.de/misc/dm-crypt/) kernel module (part of Linux). No external vendors, no proprietary formats, works across virtually all distributions.
- It’s standard, well-maintained, and scriptable. Backups and disaster-recovery (e.g., header backup) are straightforward.

## Requirements

Debian 13 (or any other Linux distro) + XFCE as desktop environment.

```bash
sudo apt update
sudo apt install cryptsetup python3-gi gir1.2-gtk-3.0 xfce4-statusnotifier-plugin
```

## Part 1 - Create the encrypted container (one-time)

Replace `~` with your actual home if you run any step as root. I’ll assume your **real** user is `$USER` and your home is `$HOME`.

### Allocate the container file

Two equivalent ways; pick **one**:

**A. `dd` (zeros, fixed size; portable):**

Creates a ~40 GiB sparse-safe file (writes zeros, shows progress)

```bash
dd if=/dev/zero of="$HOME/secure_container.img" bs=1M count=40960 status=progress
```

**B. `fallocate` (fast, sparse on some filesystems):**

Creates a ~40 GiB file instantly (works on ext4, xfs, btrfs…)

```bash
fallocate -l 40G "$HOME/secure_container.img"
```

Size: change `40960` (MiB) or `40G` as needed.

### Format the file as LUKS2

LUKS2 by default; you’ll be prompted for a new passphrase.

```bash
sudo cryptsetup luksFormat "$HOME/secure_container.img"
```

**Optional hardening** (slower unlock; stronger KDF):

Increase PBKDF memory/time (tune to your CPU/RAM; example ~128 MiB & ~2s)

```bash
sudo cryptsetup luksFormat \
  --type luks2 \
  --pbkdf argon2id \
  --pbkdf-memory 131072 \
  --pbkdf-parallel 1 \
  --iter-time 2000 \
  "$HOME/secure_container.img"
```

### Open (map) the encrypted device

*“secure_container”* is the mapper name that will appear in `/dev/mapper/`

```bash
sudo cryptsetup open "$HOME/secure_container.img" secure_container
```

### Make a filesystem inside (ext4)

Create ext4 inside the new mapper

```bash
sudo mkfs.ext4 /dev/mapper/secure_container
```

### Create a mountpoint and mount once (to test)

```bash
mkdir -p "$HOME/secure_data"
sudo mount /dev/mapper/secure_container "$HOME/secure_data"
sudo chown -R "$USER:$USER" "$HOME/secure_data"
```

### Close and clean up (end of one-time setup test)

```bash
sudo umount "$HOME/secure_data"
sudo cryptsetup close secure_container
```

## Part 2 — Command-line helper script (for daily use)

Create `~/bin/secure-container.sh`:

```bash
nano "$HOME/bin/secure-container.sh"
```

Contents:

```bash
#!/bin/bash
# Simple script to manage a LUKS container (mount / umount / status)

set -u
export PATH="/usr/sbin:/sbin:/usr/bin:/bin"

# Detect real invoking user/home even when elevated via pkexec/sudo
get_real_user_home() {
  # Prefer PKEXEC_UID (pkexec), fallback to SUDO_UID (sudo), else current
  if [ "${PKEXEC_UID:-}" != "" ]; then
    getent passwd "$PKEXEC_UID" | awk -F: '{print $1":"$6}'
  elif [ "${SUDO_UID:-}" != "" ]; then
    getent passwd "$SUDO_UID" | awk -F: '{print $1":"$6}'
  else
    echo "$(id -un):$HOME"
  fi
}

IFS=: read -r REAL_USER REAL_HOME <<<"$(get_real_user_home)"

CONTAINER="$REAL_HOME/secure_container.img"   # Path to the LUKS container file
MAPPER_NAME="secure_container"                # /dev/mapper/<name>
MOUNT_POINT="$REAL_HOME/secure_data"          # Mountpoint under user's home

# Use sudo only if not already root
if [ "$EUID" -eq 0 ]; then SUDO=""; else SUDO="sudo"; fi

err() { printf '%s\n' "$*" >&2; }

case "${1:-}" in
  mount)
    # Unlock the LUKS container (asks for passphrase)
    if $SUDO cryptsetup --tries 1 open "$CONTAINER" "$MAPPER_NAME"; then
      mkdir -p "$MOUNT_POINT"
      if $SUDO mount "/dev/mapper/$MAPPER_NAME" "$MOUNT_POINT"; then
        # Ensure the user owns the mounted directory
        $SUDO chown -R "$REAL_USER:$REAL_USER" "$MOUNT_POINT" || true
        echo "✅ Mounted at $MOUNT_POINT"
        exit 0
      else
        err "❌ mount failed"; exit 2
      fi
    else
      err "❌ Failed to unlock (wrong passphrase or KDF too tight?)."
      exit 3
    fi
    ;;

  umount)
    # Unmount and close the mapper
    if mountpoint -q "$MOUNT_POINT"; then
      if $SUDO umount "$MOUNT_POINT"; then
        if $SUDO cryptsetup close "$MAPPER_NAME"; then
          echo "✅ Unmounted and closed $MAPPER_NAME"
          exit 0
        else
          err "❌ cryptsetup close failed (mapper in use?)"; exit 4
        fi
      else
        err "❌ umount failed (probably EBUSY). Who uses it:"
        command -v fuser >/dev/null 2>&1 && fuser -vm "$MOUNT_POINT" || true
        command -v lsof  >/dev/null 2>&1 && lsof +f -- "$MOUNT_POINT" || true
        err "Tip: close terminals/file managers/editors in $MOUNT_POINT."
        exit 5
      fi
    else
      echo "ℹ️ Nothing to unmount — $MOUNT_POINT is not mounted."
      if [ -e "/dev/mapper/$MAPPER_NAME" ]; then
        $SUDO cryptsetup close "$MAPPER_NAME" && echo "🔒 Closed mapper $MAPPER_NAME" || {
          err "❌ Mapper seems open but close failed"; exit 6; }
      fi
      exit 0
    fi
    ;;

  status)
    if $SUDO cryptsetup status "$MAPPER_NAME" >/dev/null 2>&1; then
      if mountpoint -q "$MOUNT_POINT"; then
        echo "🔓 Container '$MAPPER_NAME' is OPEN and mounted at $MOUNT_POINT"
      else
        echo "🔓 Container '$MAPPER_NAME' is OPEN (not mounted)"
      fi
    else
      echo "🔒 Container '$MAPPER_NAME' is CLOSED"
    fi
    ;;

  *)
    err "Usage: $0 {mount|umount|status}"
    exit 1
    ;;
esac
```

Make it executable and add your bin to PATH:

```bash
chmod +x "$HOME/bin/secure-container.sh"
# Add to PATH for your shell (Bash):
grep -q 'export PATH="$HOME/bin:$PATH"' "$HOME/.bashrc" || \
  echo 'export PATH="$HOME/bin:$PATH"' >> "$HOME/.bashrc"
source "$HOME/.bashrc"
```

Usage:

```bash
secure-container.sh mount
secure-container.sh umount
secure-container.sh status
```

## Part 3 — Optional: unlock/mount without typing sudo password

Create a **root-owned helper** that only does mount/umount and can be called via `sudo -n` (no TTY prompt) from the GUI.

```bash
sudo nano /usr/local/sbin/secure-container-helper
```

Contents (edit the absolute paths to your user):

```bash
#!/bin/bash
# Root helper for mounting/unmounting the LUKS container via sudo -n.
# Reads passphrase from STDIN (never from argv or env).

set -euo pipefail

CONTAINER="/home/YOURUSER/secure_container.img"  # <-- change
MAPPER="secure_container"
MOUNTPOINT="/home/YOURUSER/secure_data"          # <-- change

case "${1:-}" in
  mount)
    # Unlock using passphrase from STDIN
    /usr/sbin/cryptsetup open "$CONTAINER" "$MAPPER" --type luks --key-file -
    # Mount and ensure user ownership of files
    /bin/mount "/dev/mapper/$MAPPER" "$MOUNTPOINT"
    /bin/chown -R YOURUSER:YOURUSER "$MOUNTPOINT" || true    # <-- change
    ;;
  umount)
    if mountpoint -q "$MOUNTPOINT"; then
      /bin/umount "$MOUNTPOINT"
    fi
    /usr/sbin/cryptsetup close "$MAPPER"
    ;;
  *)
    echo "usage: $0 {mount|umount}" >&2; exit 2;;
esac
```

Lock the helper down and allow **only these two subcommands** without a sudo password:

```bash
sudo chown root:root /usr/local/sbin/secure-container-helper
sudo chmod 750 /usr/local/sbin/secure-container-helper

# Create a sudoers drop-in (no password for the two actions)
sudo visudo -f /etc/sudoers.d/secure-container
```

**Put this (edit YOURUSER):**

```bash
# Allow the user to run the helper without a password
YOURUSER ALL=(root) NOPASSWD: /usr/local/sbin/secure-container-helper mount, /usr/local/sbin/secure-container-helper umount
```

Security note: the helper has a **very narrow surface** and does not accept arbitrary commands; it only toggles mount state and reads the passphrase from **STDIN** (not visible in process list or history).

## Part 4 — Tray GUI (GTK3) for mount/umount/status

Save as `~/bin/secure_container_tray.py`:

```bash
nano "$HOME/bin/secure_container_tray.py"
```

Contents:

```bash
#!/usr/bin/env python3

import os
import subprocess
import threading
from pathlib import Path
import gi
import warnings

warnings.filterwarnings("ignore", category=DeprecationWarning)
gi.require_version('Gtk', '3.0')
from gi.repository import Gtk, GLib

# ================== CONFIG ==================
HELPER = '/usr/local/sbin/secure-container-helper'  # root helper path
MOUNT_POINT = os.path.expanduser('~/secure_data')    # must match helper
CHECK_INTERVAL_SEC = 3
APP_NAME = 'Secure Container'
ICON_OK = 'emblem-ok-symbolic'
ICON_FAIL = 'dialog-error-symbolic'
# ============================================

def is_mountpoint_active(mount_point: str) -> bool:
    try:
        return subprocess.run(['mountpoint', '-q', mount_point]).returncode == 0
    except Exception:
        return False

def get_status() -> str:
    return 'mounted' if is_mountpoint_active(MOUNT_POINT) else 'closed'

def ask_passphrase() -> str | None:
    # Simple modal dialog to ask for passphrase
    dlg = Gtk.Dialog(title="LUKS passphrase", flags=Gtk.DialogFlags.MODAL)
    dlg.add_button("Cancel", Gtk.ResponseType.CANCEL)
    dlg.add_button("OK", Gtk.ResponseType.OK)
    box = dlg.get_content_area()
    box.set_spacing(8)

    label = Gtk.Label(label="LUKS passphrase:")
    label.set_xalign(0)

    entry = Gtk.Entry()
    entry.set_visibility(False)
    entry.set_invisible_char("•")
    entry.set_activates_default(True)

    reveal = Gtk.CheckButton(label="Show passphrase")
    def on_toggle(btn):
        entry.set_visibility(btn.get_active())
    reveal.connect("toggled", on_toggle)

    box.add(label); box.add(entry); box.add(reveal)
    dlg.set_default_response(Gtk.ResponseType.OK)
    dlg.show_all()

    resp = dlg.run()
    val = entry.get_text() if resp == Gtk.ResponseType.OK else None
    dlg.destroy()
    if val is None or val == "":
        return None
    return val

def run_root(cmd: list[str], input_text: str | None = None) -> tuple[bool, str, int]:
    # Run root helper via sudo -n; stdin is passed for the passphrase
    try:
        res = subprocess.run(['sudo', '-n', *cmd],
                             input=(input_text if input_text is not None else None),
                             capture_output=True, text=True)
        out = (res.stdout or '') + (res.stderr or '')
        return res.returncode == 0, out.strip(), res.returncode
    except Exception as e:
        return False, str(e), 255

def mount_flow(passphrase: str) -> tuple[bool, str]:
    logs = []
    if not os.path.exists(HELPER):
        return False, f"Helper not found: {HELPER}"
    ok, out, rc = run_root([HELPER, 'mount'], input_text=passphrase)
    logs.append(f"$ sudo -n {HELPER} mount\n(rc={rc})\n{out}")
    if not ok:
        return False, "\n\n".join(logs)
    if not is_mountpoint_active(MOUNT_POINT):
        logs.append("Sanity check failed: mountpoint is not active.")
        return False, "\n\n".join(logs)
    return True, "\n\n".join(logs)

def diagnose_busy_mountpoint() -> str:
    out = []
    for prog in (('fuser', ['fuser','-vm', MOUNT_POINT]),
                 ('lsof',  ['lsof', '+f', '--', MOUNT_POINT])):
        try:
            p = subprocess.run(prog[1], capture_output=True, text=True)
            if p.stdout or p.stderr:
                out.append((p.stdout or '') + (p.stderr or ''))
        except FileNotFoundError:
            pass
        except Exception:
            pass
    return "\n".join(s for s in out if s).strip()

def unmount_flow() -> tuple[bool, str]:
    logs = []
    if not os.path.exists(HELPER):
        return False, f"Helper not found: {HELPER}"
    ok, out, rc = run_root([HELPER, 'umount'])
    logs.append(f"$ sudo -n {HELPER} umount\n(rc={rc})\n{out}")
    if not ok:
        diag = diagnose_busy_mountpoint()
        if diag:
            logs.append("Processes using mount:\n" + diag)
        return False, "\n\n".join(logs)
    if is_mountpoint_active(MOUNT_POINT):
        logs.append("Sanity check failed: still mounted.")
        return False, "\n\n".join(logs)
    return True, "\n\n".join(logs)

class TrayApp:
    def __init__(self):
        self.win = Gtk.Window(title=APP_NAME)
        self.win.set_default_size(500, 260)
        self.win.set_position(Gtk.WindowPosition.CENTER)
        self.win.set_border_width(12)
        self.win.connect('delete-event', self.on_window_close)

        vbox = Gtk.Box(orientation=Gtk.Orientation.VERTICAL, spacing=10)
        self.win.add(vbox)

        self.status_label = Gtk.Label(label='Status: …')
        self.status_label.set_xalign(0)
        vbox.pack_start(self.status_label, False, False, 0)

        btn_box = Gtk.Box(spacing=8)
        vbox.pack_start(btn_box, False, False, 0)

        self.btn_mount = Gtk.Button(label='Mount')
        self.btn_unmount = Gtk.Button(label='Umount')
        self.btn_refresh = Gtk.Button(label='Refresh')
        self.btn_mount.connect('clicked', self.on_mount_clicked)
        self.btn_unmount.connect('clicked', self.on_unmount_clicked)
        self.btn_refresh.connect('clicked', lambda *_: self.refresh_status(silent=False))

        btn_box.pack_start(self.btn_mount, True, True, 0)
        btn_box.pack_start(self.btn_unmount, True, True, 0)
        btn_box.pack_start(self.btn_refresh, False, False, 0)

        self.msg = Gtk.TextView()
        self.msg.set_editable(False)
        self.msg.set_wrap_mode(Gtk.WrapMode.WORD_CHAR)
        self.msg.set_size_request(-1, 130)
        vbox.pack_start(self.msg, True, True, 0)

        self.tray = Gtk.StatusIcon()
        self.tray.set_from_icon_name(ICON_FAIL)
        self.tray.connect('activate', lambda *_: self.show_window())
        self.tray.connect('popup-menu', self.on_tray_popup_menu)

        self.menu = Gtk.Menu()
        self.menu_open = Gtk.MenuItem(label='Open Window')
        self.menu_mount = Gtk.MenuItem(label='Mount')
        self.menu_unmount = Gtk.MenuItem(label='Unmount')
        self.menu_quit = Gtk.MenuItem(label='Quit')
        self.menu_open.connect('activate', lambda *_: self.show_window())
        self.menu_mount.connect('activate', self.on_mount_clicked)
        self.menu_unmount.connect('activate', self.on_unmount_clicked)
        self.menu_quit.connect('activate', lambda *_: Gtk.main_quit())
        for w in (self.menu_open, self.menu_mount, self.menu_unmount, Gtk.SeparatorMenuItem(), self.menu_quit):
            self.menu.append(w)
        self.menu.show_all()

        self.refresh_status(silent=True)
        GLib.timeout_add_seconds(CHECK_INTERVAL_SEC, self._tick)
        self.win.hide()

    def on_tray_popup_menu(self, _icon, button, time):
        self.menu.popup_at_pointer(None)

    def show_window(self):
        self.win.show_all()
        self.win.present()

    def on_window_close(self, *args):
        self.win.hide()
        return True

    def _tick(self):
        self.refresh_status(silent=True)
        return True

    def set_message(self, text: str):
        buf = self.msg.get_buffer()
        buf.set_text(text)

    def refresh_status(self, silent: bool = True):
        st = get_status()
        if st == 'mounted':
            self.status_label.set_text(f"Status: 🔓 OPEN & mounted at {MOUNT_POINT}")
            self.btn_mount.set_sensitive(False)
            self.btn_unmount.set_sensitive(True)
            self.menu_mount.set_sensitive(False)
            self.menu_unmount.set_sensitive(True)
            self.tray.set_from_icon_name(ICON_OK)
        else:
            self.status_label.set_text("Status: 🔒 CLOSED")
            self.btn_mount.set_sensitive(True)
            self.btn_unmount.set_sensitive(False)
            self.menu_mount.set_sensitive(True)
            self.menu_unmount.set_sensitive(False)
            self.tray.set_from_icon_name(ICON_FAIL)
        if not silent:
            pass

    def on_mount_clicked(self, *_):
        pw = ask_passphrase()
        if pw is None:
            return
        self.run_action('mount', pw)

    def on_unmount_clicked(self, *_):
        self.run_action('umount', None)

    def run_action(self, action: str, passphrase: str | None):
        self.btn_mount.set_sensitive(False)
        self.btn_unmount.set_sensitive(False)
        self.menu_mount.set_sensitive(False)
        self.menu_unmount.set_sensitive(False)
        self.set_message(f'Running {action}…')

        def worker():
            if action == 'mount':
                ok, out = mount_flow(passphrase or "")
            else:
                ok, out = unmount_flow()
            GLib.idle_add(self._after_action, action, ok, out)

        threading.Thread(target=worker, daemon=True).start()

    def _after_action(self, action: str, ok: bool, out: str):
        rc_text = 'success' if ok else 'failure'
        self.set_message(f'{action} {rc_text}.\n\n{out}'.strip())
        self.refresh_status(silent=True)

def main():
    TrayApp()
    Gtk.main()

if __name__ == '__main__':
    main()
```

## Maintenance & useful commands

### Change passphrase / KDF parameters

```bash
# Show LUKS metadata (slots, PBKDF, etc.)
sudo cryptsetup luksDump "$HOME/secure_container.img"

# Change (add) passphrase using stronger KDF budget (example values)
sudo cryptsetup luksChangeKey \
  --pbkdf-memory=131072 --pbkdf-parallel=1 --iter-time=2000 \
  "$HOME/secure_container.img"
```

**What those do:**

- `luksDump`: prints header info, keyslots, PBKDF settings.
- `luksChangeKey`: re-derives key material with new KDF parameters and lets you set a new passphrase (or move an existing slot to new KDF cost).

### Header backup (strongly recommended)

Backup the LUKS header to a file (store OFFLINE, not next to the image!)

```bash
sudo cryptsetup luksHeaderBackup "$HOME/secure_container.img" \
  --header-backup-file "$HOME/luks_header_backup.bin"
```

If the header gets corrupted, data is unrecoverable without this. Keep the backup on another disk/cloud (encrypted).

Back up both `secure_container.img` (like any other file) **and** the header backup. Without either, corruption = data loss.

And that’s all, folks! You can use this on Whonix Workstation as an alternative to zuluCrypt.
